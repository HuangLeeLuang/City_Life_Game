# 罪城：五路亡命

可在電腦與手機瀏覽器遊玩的犯罪劇情 PWA。遊戲採現代海港城市背景，包含五章十五個依序進行的官方主線、無限遊戲日、人物關係與成長、生活與夜生活卡牌、支線任務、城市幫派、地盤爭奪、資產購買與無上限升級。

## 核心玩法

- 六項狀態：健康、疲勞、精神壓力、現金、若琳信任、街坊聲望。
- 八大能力：體能、槍法、科技、駕駛、口才、觀察、膽識、生意。
- 下午從五張生活卡牌選一張；入口包含處理日常需求、訓練玩家能力、與人見面、購買、賺錢、支線任務與必定出現的「尋找對手」。
- 五章各有三個官方主線任務，嚴格依序出現。下一個待辦主線會和四張生活卡一起出現在上午；玩家可以主動選擇進行，也能先過生活。未選主線不受日期或階段限制，會永久保留直到完成。
- 每章第三個任務完成後顯示章節轉場；官方十五個任務完成後顯示結局，但遊戲可繼續無限自由遊玩。自訂主線只會在官方主線後依建立順序出現。
- 晚上從五張夜生活卡牌選一張；40張內容涵蓋住宿、飲食、娛樂、人物活動、高風險活動、產業活動，以及高報酬槍戰與格鬥。
- 城市勢力包含九個風格與戰力不同的幫派，以及十五塊會產生每日收入的地盤；玩家能反覆挑戰巡街隊、攻佔地盤、招募隊伍、強化防守並處理敵方反攻。
- 五名聯絡人提供常駐支援；十名有姓名與背景的核心隊員最多編制五人出勤。所有人物都能透過「與人見面」無上限升級，等級越高突破率越低；關係在升級失敗時仍會增加。
- 狄菲在新遊戲開始時便以助理／護衛身分加入並出勤；她有三段依關係解鎖、永久保留的人物事件。程嵐會在第一章完成後加入聯絡人與核心隊員名單。
- 戰鬥可使用射擊、近身格鬥、環境科技、掩護或主動撤離；街頭人手、核心隊員、武器、戰術物品、車輛、產業與地盤數量都會影響實戰能力。
- 支線任務首次抽三選一；進行中的任務再次使用支線卡時會直接接續。
- 分類市場共有 32 種資產：3 項房產、4 輛車、7 種武器、6 種戰術物品、2 項奢侈品與 10 種產業。所有項目均可無上限升級；產業提供被動收入及戰鬥或經營專長。
- 休閒活動可產生持續五個階段的短期效果。
- 六項屬性與八大能力保持常駐；城市勢力、短期效果、支線、資產與世界紀錄預設收合，需要時再點擊展開。
- 遊戲內修改器可調整狀態、關係、城市數值與八大能力，也能新增或修改卡牌；所有內容保存在本機存檔。

## 開始遊戲

最簡單的方式是直接雙擊專案根目錄的 `index.html`。遊戲圖片與本機存檔都能正常使用，不需要先啟動伺服器。

若要測試 PWA 安裝、Service Worker 或模擬正式網站環境，可在 Windows 執行 `start-game.ps1`，或在專案資料夾執行：

```powershell
npm run serve
```

接著開啟 `http://127.0.0.1:4173`。首次載入後，瀏覽器會快取必要檔案，可安裝到手機主畫面並離線遊玩。直接雙擊模式不會啟用 Service Worker，但不影響遊戲與存檔。

修改 `src` 內的程式後，請重新產生可直接開啟的版本：

```powershell
npm install
npm run build
```

## 測試

```powershell
npm test
```

測試涵蓋牌堆生成、十五個主線順序、無限日數、章節轉場、結局後自由遊玩、舊存檔遷移、人物關係與升級、聯絡人支援、生活活動、支線任務、戰鬥、資產購買與升級。
