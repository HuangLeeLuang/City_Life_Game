# 罪城：五路亡命

可在電腦與手機瀏覽器遊玩的純文字犯罪劇情 PWA。遊戲採現代海港城市背景，包含五章二十五天主線、生活卡牌、夜生活卡牌、支線任務、能力成長、城市幫派、地盤爭奪、資產購買與無上限升級。

## 核心玩法

- 六項狀態：健康、疲勞、精神壓力、現金、若琳信任、街坊聲望。
- 八大能力：體能、槍法、科技、駕駛、口才、觀察、膽識、生意。
- 下午從五張生活卡牌選一張；入口包含處理日常需求、訓練、見面、購買、賺錢、支線任務與必定出現的「尋找對手」。
- 待辦主線會和四張生活卡一起出現在上午五張牌中；玩家可以主動選擇進行，也能先過生活，主線會保留到下一個上午。
- 晚上從五張夜生活卡牌選一張；40張內容涵蓋住宿、飲食、娛樂、人物活動、高風險活動、產業活動，以及高報酬槍戰與格鬥。
- 城市勢力包含九個風格與戰力不同的幫派，以及十五塊會產生每日收入的地盤；玩家能反覆挑戰巡街隊、攻佔地盤、招募隊伍、強化防守並處理敵方反攻。
- 可招募八名有姓名與背景的核心隊員，最多編制四人出勤；近戰手、槍手、駭客、車手、軍醫、偵察手、談判手與營運手會提供不同戰鬥、撤離、醫療、報酬及收入效果，並可無上限訓練升級。
- 戰鬥可使用射擊、近身格鬥、環境科技、掩護或主動撤離；街頭人手、核心隊員、武器、戰術物品、車輛、產業與地盤數量都會影響實戰能力。
- 支線任務首次抽三選一；進行中的任務再次使用支線卡時會直接接續。
- 分類市場共有 32 種資產：3 項房產、4 輛車、7 種武器、6 種戰術物品、2 項奢侈品與 10 種產業。所有項目均可無上限升級；產業提供被動收入及戰鬥或經營專長。
- 休閒活動可產生持續五個階段的短期效果。
- 六項屬性與八大能力保持常駐；城市勢力、短期效果、支線、資產與世界紀錄預設收合，需要時再點擊展開。
- 遊戲內修改器可調整狀態、關係、城市數值與八大能力，也能新增或修改卡牌；所有內容保存在本機存檔。

## 開始遊戲

在 Windows 執行 `start-game.ps1`，或在專案資料夾執行：

```powershell
npm run serve
```

接著開啟 `http://127.0.0.1:4173`。首次載入後，瀏覽器會快取必要檔案，可安裝到手機主畫面並離線遊玩。請勿直接以 `file:///` 開啟，因為瀏覽器會限制模組與離線功能。
