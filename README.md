# 罪城：五路亡命

可在電腦與手機瀏覽器遊玩的純文字犯罪劇情 PWA。遊戲採現代海港城市背景，包含五章十五天主線、生活卡牌、夜生活卡牌、支線任務、能力成長、資產購買與無上限升級。

## 核心玩法

- 六項狀態：健康、疲勞、精神壓力、現金、若琳信任、街坊聲望。
- 八大能力：體能、槍法、科技、駕駛、口才、觀察、膽識、生意。
- 下午從五張生活卡牌選一張；入口包含處理日常需求、訓練、見面、購買、賺錢、支線任務。
- 主線只在章節關鍵日出現；沒有主線的上午同樣改抽五張生活卡牌。
- 晚上從五張夜生活卡牌選一張；24張內容涵蓋住宿、飲食、娛樂、人物活動、高風險活動與產業活動。
- 支線任務首次抽三選一；進行中的任務再次使用支線卡時會直接接續。
- 可購買及升級房產、車輛、武器、奢侈品與產業。產業會提供被動收入。
- 休閒活動可產生持續五個階段的短期效果。
- 遊戲內修改器可調整狀態、關係、城市數值與八大能力，也能新增或修改卡牌；所有內容保存在本機存檔。

## 開始遊戲

在 Windows 執行 `start-game.ps1`，或在專案資料夾執行：

```powershell
npm run serve
```

接著開啟 `http://127.0.0.1:4173`。首次載入後，瀏覽器會快取必要檔案，可安裝到手機主畫面並離線遊玩。請勿直接以 `file:///` 開啟，因為瀏覽器會限制模組與離線功能。

## 測試

```powershell
npm test
```

測試涵蓋牌堆生成、完整流程模擬、生活活動、短期效果、支線任務、資產購買與升級。
