# 罪城：五路亡命

可在電腦與手機瀏覽器遊玩的犯罪劇情 PWA。遊戲採現代海港城市背景，包含五章十五個依序進行的官方主線、無限遊戲日、人物關係與成長、生活與夜生活卡牌、支線任務、城市幫派、地盤爭奪、資產購買與無上限升級。

## 核心玩法

- 六項狀態：健康、疲勞、精神壓力、現金、若琳信任、街坊聲望。
- 八大能力：體能、槍法、科技、駕駛、口才、觀察、膽識、生意。
- 下午從五張生活卡牌選一張；入口包含處理日常需求、訓練玩家能力、與人見面、購買、賺錢、支線任務與必定出現的「尋找對手」。
- 五章各有三個官方主線任務，嚴格依序出現。下一個待辦主線會和四張生活卡一起出現在上午；玩家可以主動選擇進行，也能先過生活。未選主線不受日期或階段限制，會永久保留直到完成。
- 每章第三個任務完成後顯示章節轉場；官方十五個任務完成後顯示結局，但遊戲可繼續無限自由遊玩。自訂主線只會在官方主線後依建立順序出現。
- 晚上從五張夜生活卡牌選一張；40張內容涵蓋住宿、飲食、娛樂、人物活動、高風險活動、產業活動，以及高報酬槍戰與格鬥。
- 城市勢力包含九個風格與戰力不同的幫派，以及十五塊會產生每日收入的地盤；互動式城市地圖會依控制勢力即時著色，標示情報鎖定與反攻警報，並可直接定位到地盤卡。玩家能反覆挑戰巡街隊、攻佔地盤、招募隊伍、強化防守並處理敵方反攻。
- 五名聯絡人提供常駐支援；十名有姓名與背景的核心隊員最多編制五人出勤。所有人物都能透過「與人見面」無上限升級，等級越高突破率越低；關係在升級失敗時仍會增加。日間見面、夜間邀約、人物事件與交流結果都會顯示對應人像、關係進度與角色資訊。
- 狄菲在新遊戲開始時便以助理／護衛身分加入並出勤；她會以可隱藏的全身立繪常駐介面，依急迫事件、傷勢、支線期限與戰鬥狀況提出可直接執行的建議。沒有急迫事項時，玩家可在大型複選面板逐項勾選賺錢、八種訓練及八種日常恢復／成長活動，狄菲只會從已勾選且目前能負擔的項目中隨機建議；選擇會持續保留。接受建議並完成行動後，也能直接在助理對話框按「繼續」。她另有三段依關係解鎖、永久保留的人物事件。程嵐會在第一章完成後加入聯絡人與核心隊員名單。
- 戰鬥可使用射擊、近身格鬥、環境科技、掩護或主動撤離；畫面會列出本次出勤核心隊員的人像、職務、等級與專長。街頭人手、核心隊員、武器、戰術物品、車輛、產業與地盤數量都會影響實戰能力。
- 支線任務首次抽三選一；進行中的任務再次使用支線卡時會直接接續。人物、犯罪與城市三類支線各有桌機／手機專用情境圖。
- 分類市場共有 32 種資產：3 項房產、4 輛車、7 種武器、6 種戰術物品、2 項奢侈品與 10 種產業。所有項目均可無上限升級；產業提供被動收入及戰鬥或經營專長。
- 休閒活動可產生持續五個階段的短期效果。
- 六項屬性與八大能力保持常駐；生活、夜生活、狀態、支線與戰鬥行動都有清楚的介面圖示。上午、下午與夜晚有不同環境色調，行動結果會以成功或代價狀態強調；城市勢力、短期效果、支線、資產與世界紀錄預設收合，需要時再點擊展開。
- 遊戲內修改器可調整狀態、關係、城市數值與八大能力，也能新增或修改卡牌，並可用本機圖片替換狄菲的常駐助理全身圖或十名核心隊員人像；所有內容只保存在本機，不會上傳。

## 每日部署與自動運作

每天早上都會先進入由狄菲主持的部署階段。她會依隊員的戰備、已持有產業、控制地盤與當前威脅提出出勤與任務建議；玩家可在確認前自行替換隊員、任務或目標。確認後，出勤名單會在上午、下午與晚上三個階段各結算一次，晚間日結後才會進入下一天的部署。

確認部署後可選擇「自動完成今天」或「持續自動運作」。兩種模式會優先使用狄菲助理設定中已儲存、已勾選的一般行動範圍；若沒有可執行的勾選行動，狄菲會安全改用免費休息或短期工作，不會讓現金變成負數。前者在當日結束後停止，後者會跨日重新部署並繼續。無論哪一種模式，官方主線、支線任務及其接受／放棄選項都必須由玩家手動決定，絕不會被自動選取。

敵方進攻會立即強制停止自動運作，並顯示警報等待玩家確認與手動進入戰鬥。停止自動運作的要求會在安全的階段邊界生效；重新整理或重新開啟遊戲後，連續模式也不會自動恢復。

## 開始遊戲

最簡單的方式是直接雙擊專案根目錄的 `index.html`。遊戲圖片與本機存檔都能正常使用，不需要先啟動伺服器。

若要測試 PWA 安裝、Service Worker 或模擬正式網站環境，可在 Windows 執行 `start-game.ps1`，或在專案資料夾執行：

```powershell
npm run serve
```

接著開啟 `http://127.0.0.1:4173`。首次載入後，瀏覽器會快取必要檔案，可安裝到手機主畫面並離線遊玩。直接雙擊模式不會啟用 Service Worker，但不影響遊戲與存檔。

修改 `src` 內的程式後，請重新產生可直接開啟的版本：

```powershell
npm install
npm run build
```

### 手機遊戲圖示

`assets/icons/icon-master.png` 是 1024×1024 的不透明主圖。若要重新產生 PWA、Android maskable、Apple Touch 與 favicon 圖示，請使用已安裝 Pillow 的 Python 執行：

```powershell
python scripts\build-icon-assets.py
```

完成後執行 `node scripts/icon-assets.mjs`，檢查實際尺寸、透明度、manifest、HTML 連結與離線快取清單是否一致。
