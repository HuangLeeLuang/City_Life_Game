# 市場批次購買與一次結帳設計

## 目標

把目前「點一件商品就立即扣款並離開市場」的流程改為購物車。玩家可以跨武器、物品、車輛、房產、產業、奢侈品等分類選擇多件商品，確認完成後一次驗證、一次扣款、一次結算，整次購物仍只消耗一個生活階段。

## 購物車範圍

購物車可同時包含：

- 尚未持有的永久資產購買項目。
- 已持有資產的一級升級項目。

目前所有市場商品都是唯一永久資產，同一資產不能選擇數量或重複購買。架構保留未來消耗品數量欄位的擴充空間，但本次不加入消耗品或多數量 UI。

每項既有資產在同一筆交易最多升一級；同一筆交易中新購的資產不能立刻加入升級項目。

## 介面與互動

- 商品卡由立即購買按鈕改為可選取卡片或核取方塊，選取狀態清楚顯示。
- 切換或收合市場分類不會清空其他分類的選取。
- 已持有商品維持停用並標示「已持有」。
- 升級列表顯示目前等級、下一級費用與成功率，可加入同一購物車。
- 手機畫面底部固定購物車列，顯示件數、總價、目前現金、結帳後餘額、清空與「確認結帳」。
- 玩家可以暫時選到總價高於現金的組合以便比較；此時餘額與警告顯示紅色，確認結帳停用。
- 購物車空白時確認結帳停用。
- 點「暫不購買」時，若購物車非空，必須先確認是否放棄；放棄後不扣款、不套用效果，但仍消耗這個生活階段。

購物車是 `app.mjs` 的暫存 UI 狀態，不寫入遊戲存檔。重新整理、載入其他存檔或離開市場都會清空，因而不會在重整後重複送出交易。

## 交易資料

UI 送入引擎的是結構化行項目，不直接傳送效果陣列：

- 購買：`{ kind: "purchase", choiceId }`
- 升級：`{ kind: "upgrade", category, assetId, expectedLevel }`

引擎只接受目前 `asset_market` 內存在的選項及玩家確實持有的資產。`expectedLevel` 必須等於送出時的實際等級，避免過期畫面用舊價格升級。

## 原子結帳

新的市場結帳引擎函式先完整驗證，再在複製狀態上依固定順序處理：

1. 購物車不可為空，行項目不可重複。
2. 每個購買選項必須存在、包含合法 `asset.grant`，且玩家尚未持有。
3. 每個升級項目必須存在、仍為預期等級，且不是同筆新購資產。
4. 依目前商品價格及升級公式重新計算總價，不信任 UI 傳入的金額。
5. 總價不得超過玩家現金。
6. 驗證全部通過後，先按市場分類及商品原始順序套用購買，再按分類與資產 ID 排序處理升級亂數。
7. 整筆流程只回傳一次新狀態與一次結果紀錄。

驗證失敗時原狀態完全不變：不扣部分金額、不加入部分資產、不消耗亂數，也不寫入部分紀錄。

按下確認結帳後，購物車與所有結帳控制立即鎖定，直到引擎回傳成功或錯誤；快速連點、觸控重複事件及 Enter 重送都不能提交第二筆交易。若引擎拒絕交易，解除鎖定並保留購物車，讓玩家修正失效項目。

升級檢定失敗屬於合法的交易結果，不是交易驗證失敗：該升級費用仍會扣除，資產維持原等級，其他購買與升級照常完成。固定處理順序可確保存檔種子相同時結果可重現。

## 效果與結果畫面

購買商品沿用每個市場選項現有的完整 effects，包括現金支出以外的能力、世界數值、資產戰鬥或收入效果。引擎不再逐件進入 result；所有效果完成後才顯示單一「市場結帳」結果。

結果資料包含：

- 成功購買的商品名稱與價格。
- 每項升級的原等級、目標等級、費用及成功／失敗。
- 總支出與剩餘現金。
- 由商品帶來的主要能力或世界變化摘要。

交易本身成功提交時，結果狀態視為成功；個別升級失敗在明細內顯示，不把已完成的合法交易誤標成系統錯誤。

## 階段與相容性

- 一次結帳無論包含一件或多件，都只結束當前的購物生活階段一次。
- 空購物車離開沿用既有規則：保留現金但消耗生活階段。
- 既有單件商品資料、資產存檔結構、升級價格與成功率公式不改。
- 既有 `resolveActivity` 的其他生活活動不受影響；市場改用專用 `checkoutMarket`，不再讓商品卡直接呼叫單件 `resolveActivity`。
- 舊存檔不需要保存或遷移購物車。

## 可及性與手機版

- 每張商品卡以原生 checkbox 語意或等價的 `aria-pressed` 表達選取狀態。
- 購物車總額變化使用 `aria-live="polite"`，不在每次勾選搶走鍵盤焦點。
- 固定購物車列保留足夠底部安全區，不遮住最後一張商品與手機瀏覽器工具列。
- 分類 details、商品按鈕與升級列均可用鍵盤操作；錯誤訊息會指出是哪個項目失效。

## 驗收條件

- 可跨至少兩個分類選取多件商品，分類收合後購物車仍保留。
- 總價與結帳後餘額正確；總價超過現金時無法送出。
- 成功結帳只扣一次總價、一次加入所有資產、一次進入結果畫面並只消耗一個階段。
- 任一商品重複、已持有、未知、升級等級過期或資金不足時，整筆狀態與亂數種子完全不變。
- 同筆升級依固定順序擲骰；升級失敗仍扣該項費用但不影響其他合法項目。
- 新購資產不能在同一筆交易升級；既有資產每筆最多升一級。
- 放棄非空購物車需要確認，確認放棄後不產生任何資產或扣款。
- 重新整理不會恢復或重送未結帳購物車。
- 360px 寬度下固定購物車列可讀、可點擊且不遮住商品。
- Node 引擎測試、DOM／UI 測試、離線建置與直接雙擊 `index.html` 均通過。
