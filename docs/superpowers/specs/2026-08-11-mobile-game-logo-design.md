# 手機遊戲 LOGO 設計

## 目標

替換目前手機安裝圖示。現有圖示同時使用寫實電話、吊橋、雨景、放射道路與大量材質，放大時有氣氛，但縮到手機桌面、啟動畫面或 32px favicon 時輪廓互相黏合，無法快速辨認。

新 LOGO 要在一眼之內表達「現代港灣城市、勢力部署、經營與犯罪衝突」，並在常見手機裁切形狀與小尺寸下維持清楚。

## 核心概念

採用「城市勢力地圖徽記」：

- 上半部是極簡港灣城市天際線或橋樑弧線，表達海港市。
- 下半部是五條粗而清楚的道路／勢力線，匯聚到中央節點，呼應《罪城：五路亡命》的五路、地盤與每日部署。
- 中央節點帶一個小型紅色警戒光點，表示敵方進攻與城市危機。
- 整體形成單一強輪廓的徽記，而不是一幅縮小的場景插畫。

不採用人物臉部、槍枝、細小電話、文字縮寫或完整遊戲名稱。人物會讓玩家誤以為是單一角色遊戲，槍枝與準星會讓圖示看起來像純射擊遊戲，文字則在小尺寸失去辨識度。

## 視覺規格

- 正方形、全幅不透明深色底，不依賴透明邊緣。
- 背景為深墨綠至近黑的低對比漸層，延續現有遊戲介面的夜間港市色調。
- 城市與道路使用暖金色，主線條必須足夠粗，在 32px 時仍能分開。
- 警戒節點使用單一暗紅／緋紅色，不加入多個發光點。
- 可保留輕微霧光與金屬質感，但禁止雨絲、磚石刮痕、小窗戶、細纜線等縮小後會變雜訊的細節。
- 不含文字、數字、人物、槍械、浮水印或外框內的小裝飾。

主徽記必須完整落在中央 66% 的 maskable 安全區內；外圍 17% 僅放可被裁掉的深色背景與微弱光暈。用圓形、圓角矩形、方形與 Android maskable 裁切時，五條道路、天際線和紅色節點都不能缺失。

## 素材流程

1. 以已核准的文字規格生成 1024×1024 候選圖。
2. 檢查幾何輪廓、五條道路數量、中央安全區及禁止元素；若生成結果出現小字、槍械或過多細節，重新生成或局部修正。
3. 選定後保存為 `assets/icons/icon-master.png`。
4. 由同一主檔以高品質縮圖輸出，不分別重新生成各尺寸，確保所有平台使用相同徽記。

需要覆寫的成品：

- `assets/icons/icon-512.png`：512×512，`purpose: any`。
- `assets/icons/icon-maskable-512.png`：512×512，保留 maskable 安全區。
- `assets/icons/icon-192.png`：192×192，`purpose: any`。
- `assets/icons/apple-touch-icon.png`：180×180，不透明背景。
- `assets/icons/favicon-32.png`：32×32；必要時輕微加粗主線與提高對比，但不得改變徽記構圖。

現有檔名與 manifest 路徑保持不變，因此 `index.html`、`play.html`、service worker 快取清單及安裝路徑不需要改名。若瀏覽器快取無法即時更新，調整 service worker 快取版本或圖示引用版本，讓已安裝使用者取得新圖。

## 範圍界線

本次只替換 PWA 安裝圖示、Apple Touch Icon、manifest 圖示與 favicon。遊戲標題、開始畫面主視覺、人物圖、事件插圖與戰鬥動畫不因 LOGO 更動而重做。

新 LOGO 不加載任何執行時圖片生成或外部服務；所有檔案隨遊戲離線保存，直接雙擊 `index.html` 仍可遊玩。

## 驗收條件

- 主圖明確包含港灣城市／橋樑輪廓、五條匯聚勢力線與單一紅色警戒節點。
- 不含文字、人物、槍械、浮水印或縮小後成為雜訊的寫實細節。
- 32px 實際尺寸仍可辨認主要金色徽記，五條線不糊成單一色塊。
- 180px、192px 與 512px 圖示比例一致、無拉伸、無透明黑邊。
- 圓形、圓角矩形、方形及 maskable 裁切都不截斷主體。
- manifest 宣告尺寸、實際 PNG 尺寸、HTML icon 連結與 service worker 快取項目一致。
- 手機安裝後顯示新圖示；一般瀏覽器分頁顯示新 favicon。
- 圖片稽核、離線建置與直接雙擊 `index.html` 均通過。
